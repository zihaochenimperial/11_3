# P1817 local CUDA compatibility preflight

Date: 2026-11-04. Source commit `03088368d42684fb54225c981cfd94b58cc0393a`.

- Host: RTX 3070 Ti Laptop 8 GB, Windows driver 546.30; WSL Ubuntu 22.04 sees the GPU. No `nvcc` initially, no passwordless `sudo` in the WSL user.
- Separate environment `/home/research/msc_inverse_research/envs/p1817` has Python 3.11.10, PyTorch 2.4.1+cu121, torchvision 0.19.1+cu121; `torch.cuda.is_available()` returned true and identified the RTX 3070 Ti. The other Image-GS Python dependencies from `environment.yml` have been installed.
- The official `environment.yml` uses PyTorch 2.4.1 with CUDA 12.4. This local CUDA 12.1 choice is an explicit **compatibility environment** for the current driver, supported by the [PyTorch 2.4.1 wheel matrix](https://pytorch.org/get-started/previous-versions/) and [NVIDIA 12.1 driver requirements](https://docs.nvidia.com/cuda/archive/12.1.0/cuda-toolkit-release-notes/). It cannot be presented as an exact official-environment reproduction.
- Bundled `gsplat` and `fused-ssim` have CUDA extensions. The `nvidia-cuda-nvcc-cu12` Python wheel is not a complete `nvcc` compiler ([NVIDIA issue](https://github.com/NVIDIA/cuda-python/issues/2100)); the CUDA 12.1 Toolkit-only runfile was downloaded and verified under `/home/research/msc_inverse_research/toolchains/downloads/`. It is 4,317,456,991 bytes, SHA-256 `d74022d41d80105319dfa21beea39b77a5b9919539c0487a05caaf2446d6a70e`. Its MD5 `2f0a4127bf797bf4eab0be2a547cb8d0` matches the [official NVIDIA checksum list](https://developer.download.nvidia.com/compute/cuda/12.1.1/docs/sidebar/md5sum.txt). Toolkit only was installed at `/home/research/msc_inverse_research/toolchains/cuda-12.1`; `nvcc` reports 12.1.105. No Linux or Windows driver was changed. Both `fused-ssim` (commit `a7c48d6dd7ac6dc39a7958c7c4452e0b10418f38`) and the bundled `gsplat` compiled and installed into the isolated P1817 environment.
- Running the official source from its root requires `PYTHONPATH=/home/research/msc_inverse_research/src/image-gs/gsplat` because the outer `gsplat/` directory shadows the nested Python package. `pyyaml==6.0`, declared in the bundled gsplat development extras, was also installed. These are local environment fixes, not model-code modifications.
- A deterministic 192×192 RGB clean/noisy synthetic pair was generated with sigma 25/255 and seed 123; manifest and pixels are under `/home/research/msc_inverse_research/data/p1817_smoke192/`. Two 50-step, 512-Gaussian smoke runs finished with exit 0, checkpoint and rendered PNG: clean input, then noisy input. The 64×64 attempt reached optimization but the official final MS-SSIM needs side length above 160, so it was replaced by 192×192 without changing the evaluator. The noisy run included Gaussian birth at steps 10 and 20. Logs and output are under `/home/research/msc_inverse_research/runs/p1817_smoke_20261104/`.
- Independent RGB 8-bit PSNR (`scripts/verify_image.py`) against the known clean image: noisy input 20.3394 dB; noisy-run render 14.7930 dB; clean-run render 14.6199 dB. The official noisy-run 13.80 dB is against its **noisy input**, which the independent evaluator reproduces as 13.8005 dB. The 50-step render is worse than the noisy input against clean truth. This is **infrastructure smoke only**, not a denoising baseline or negative conclusion about the method. Clean run took 17.09 s including first-time AlexNet weight download; noisy run took 6.43 s whole-command time, peak process RSS 1,810,328 KB. VRAM peak has not been recorded.
