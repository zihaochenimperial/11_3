## 2. 候选 A′：高斯尺度半群下的噪声校准证书
### 2.1 痛点与形式
- 痛点：K 的选取（致密化/停止）要么是无保证的启发式，要么要验证拟合（RAWcv ≥2 额外拟合）。
- 形式（SFW 同形，回执 R5，部分阅读）：`min_{m≥0} ½‖y−Φm‖² + λ|m|(Θ)`，`Φm=∫ g_θ dm(θ)`，证书 `η_λ(θ)=λ⁻¹⟨g_θ, y−Φm⟩`，KKT：`sup|η|≤1`；birth = |η| 的极大点，`sup|η|≤1+tol` 停止；λ 由纯噪声下 `sup_θ|⟨g_θ,w⟩|` 的分位数校准。
- **半群事实（Sonnet 数值核验，成立）**：Σ⪰Σ₁ 时 `g_Σ = g_Σ₁ * g_{Σ−Σ₁}`（误差 3e-8）。⇒ ① **L1 归一化**：同一图像任何正表示的总质量相同，BLASSO 罚项恒定，**无稀疏偏好**；② **L2 归一化**：窄混合/宽原子的罚项比 = (|Σw|/|Σn|)^{1/4}（实测 2.000/1.826 与理论吻合），**隐含偏爱宽原子的尺度先验**；③ 纯噪声 sup 的 argmax 位置由归一化决定：L2 下 50% 落在最小尺度、L1 全落在最小尺度、峰值归一化几乎全落在最大尺度（仅各向同性）。所以"校准 λ"不是一个中性动作，K_cert 由归一化选择决定。
### 2.2 方法差异（只主张这一条，且仍是 proposed）
不是"SFW 换成各向异性高斯"，而是：**在位置+尺度+朝向的多元高斯字典上（Poon–Keriven–Peyré 自述的开放区），尺度嵌套使稀疏性/证书理论的适用性成问题（Opus 论断：代数我已核验；理论迁移未核验，应放进 Fisher 几何里重述），需要选择归一化 + 噪声校准并检验拟合后是否仍校准**。这条差异是否**有科学价值**取决于 M1/M3，尚未知；它也可能就是"致命缺陷"（Opus：二者必居其一）。

### 2.4 最强反驳与诚实原创度
1. 骨架（贪心加点 + 联合精修 + 证书 + 噪声校准）在 SFW/ADCG/CL-OMPR/Azaïs/Butucea 中几乎全有 ⇒ 若半群/归一化问题被解决得"平凡"，原创度**低**；仅当得到**可检验的校准停止规则且在已知-σ 平凡规则之上非劣**，才到**中**。我的自评：**低到中，且读到 Giard 等 2025 后偏低**：不预先承诺；可辩护的新意只可能在"噪声校准 + 拟合后校准/停止 + 图像加性噪声模型"的经验/算法层，而非证书理论本身。
2. 通用阈值保守：纯噪声 sup 由最小尺度细胞主导，λ 可能处于像素级通用阈值，K_cert 对平滑内容≈0（Opus 预测。**我的 §C 粗算既不证实也不推翻它**：它比较的是**拟合前、孤立、各向同性**斑的自响应与各向同性纯噪声 sup 的**均值**；而 Opus 的预测针对 K0=24 拟合**后残差**上的证书（D1 斑此时已被吸收），且校准应取高分位数、加上朝向/长宽比会抬高 sup。粗算与两种结果都相容，**未检验**；见 `REIDEA_M1_M2_CHECKS_20261105.md` §C 的更正）。
3. 模型误设：自然图像非稀疏高斯和，残差结构化；对"停止证书"在自然图像上是致命的，在 well-specified 合成图上不是。
4. **基准余量小（新）**：见 §0-2，≤2.8 pp。
5. ℓ₁ 收缩偏差/支撑选择 λ ≠ 风险最优 λ；非凸滑动使证书仅局部有效。

| **M4 开发集** | 新图 k≥61、新 seed、**R_MAX≥6**、基准 K* 跨 {4…64}、单原子 SNR 跨阈值；归一化/滤波器网格/λ 规则**事前冻结**（不得"残差结构化时再下调 λ"） | 对 {Cp 朴素、Cp 含搜索 df、discrepancy、best-fixed-R、fission-CV(τ 匹配)、RAWcv} 中最优者不**非劣**（2% 边际），或成本 >1.2 拟合当量 ⇒ 杀死 |
| **M5** | 独立封存确认（新图新 seed；自然图像来源另议，外网受限） | 预注册 |
- 强制基线（Opus r9+r10）：**参数 bootstrap 校准的全局 discrepancy principle**（σ 已知时整条 拟合→滑动→sup 流程可数值校准，含拟合后/选择后；这是对 A′ 作为方法的最强反对，与基准无关）、Cp 朴素/含搜索 df、best-fixed-R、fission-CV τ 匹配、RAWcv，以及**分块（windowed）discrepancy**（按图块局部 RSS + Bonferroni）——后者若与证书持平，证书无价值。滤波器网格（6 尺度 × 8 朝向 × 3 长宽比）与归一化在看到任何 dev 图像前冻结。
### 2.6 算力
M0/M1 纸面 + 白噪声，CPU 秒–分钟。M3/M4 若执行：证书求值约 150 滤波器 × FFT，64×64 毫秒级；一次拟合约数 CPU 秒（CF0：约 1.08 万拟合当量在 131 分钟内完成）；M3–M4 粗估 30–120 核·分钟，**未冻结预算**。大 GPU 只在 ≥1024² 批量时才有意义；24–36GB（4090 级）仅为估算、未实测、不购买；本机 8GB 卡对 ≤1024² 多半够用。

## 3. 候选 C′：可辨识性诊断（并入 A′）
- 对原子 k 的参数块取邻居补偿后的 Schur 补 `I_k=J_kᵀ(I−P_{−k})J_k/σ²`。**v1 的"重参数化不变"撤回**（特征值随参数化——Cholesky vs 旋转缩放——改变；阈值"半像素/半尺度"是参数单位）。不变的对象是**几何量**：原子 k 切空间与其邻居张成空间之间的**主角度**（或投影扰动的像空间范数）。
- 与 A′ 的联系（Opus 指出且我认同）：半群近共线（宽原子 vs 邻近窄原子）正是小主角度，所以 C′ 是 A′ 内的**可辨识性诊断**，不是第二个贡献。
- **H-C1 须加分层压力测试并预注册方向性预测**：重叠度扫描、分离度扫描、低 SNR 格；预测"在哪个区域比值离开 [0.5,2]"。否则它近似单元测试（高 SNR 且分离良好时渐近有效性几乎保证通过）。
- merge/freeze 并非本项目已证实的瓶颈；H-C2 须对"同 K 下剪枝"基线，不单独推进。

## 4. 候选 B / D / E（简）
B：Azaïs–De Castro–Mourareau（部分 L4，一维平稳）与 Kac–Rice（L2+）已占，**仅作 A′ 的校准部件**。D：区域级 fission，增量，Lepski/AWS/VGNC 先验。E：Wolf–Ziv 分离原理使独立贡献小。三者都不单独推进。

## 5. 推荐与诚实评估（v3）
- **Opus r10 的建议（我如实转述；是建议，不是真人决定）**：①现有路线（含 A′）**缺乏足以承载"原创性贡献"的新意**，建议如实报告；②理由：证书理论白区只剩"每原子方向各异且未知"，作者自述难、非硕士级；纯噪声 sup 律是经典对象；σ 已知时校准可由参数 bootstrap 数值完成，解析证书无实用优势；证书/算法骨架在 SFW/ADCG/CL-OMPR；基准余量小（且仅 18 图 in-sample）；③**保留"边界结果"**：已知 σ 下，这些基准上的 2D 高斯拟合 K 选择被廉价全局规则/RAWcv 捕获（待 M2b 补齐 RSS 规则后才可下此结论）；开放理论问题 = 方向各异的 BLASSO 证书（Giard 等 §7）。
- **Opus 只接受的继续形式 A″（局部 vs 全局停止）**：假设——**当失配在空间上集中（图中某区域欠拟合、其余拟合良好）时，全局 RSS 规则（discrepancy/Cp）会因 χ² 稀释而过早停止，局部 sup 统计量不会；在弥散失配下证书应当输**（方向来自理论，不来自方法）。需**事前固定的生成器族**（K* 对数均匀 {4…64}；单原子 SNR 取预先算好的零假设 sup 分位数的 {0.5,1,2,4} 倍；旋转/长宽比自由；重叠扫描；**空间异质因子**=K* 集中于子窗口的比例；一类误设（边/纹理）；R_MAX≥6），并**事前写明每个格子预期哪个基线赢**。杀死：(i) M0 发现位置/尺度/旋转 sup 校准 + 贪心高斯 birth 已存在；(ii) M4 集中失配格子中证书对**分块 discrepancy**的 NU 优势 ≤2%；(iii) 成本 >1.2 拟合当量；(iv) M3 拟合后假 birth 率 >2α。最强反驳：分块 discrepancy + 参数 bootstrap 大概率以极低成本做同样的事——那就只是有用的负结果。
- **不推荐**：半群重表述（多尺度高斯图像 = g_Σmin * 正测度）——使 K 不可识别，无法选 K，要选 K 需描述长度/率准则，即候选 E（低原创度）；"类型识别"即 discrepancy principle 换名。
- **进入 A″ 的前置（都不需合同的纸面工作先做）**：Shafie 等 2003 精读到 L4；Siegmund–Worsley 1995；Azaïs §6；Giard 的 v3 §3–§5（核对 v2/v3 是否加入方向）；Hardy 2023；ADCG；CL-OMPR；Elvira 等。**第一个可执行里程碑 = M2b**：在现有 dev 设计上重跑并记录逐轮 RSS，然后在现有表上评估 bootstrap 校准全局 discrepancy、分块 discrepancy、证书——**这是新实验，须新合同 + 真实 Opus + 冻结**。
- 我自己的原创度自评：**低**（v2 的"低到中"已不再支持）；v2 里"硕士可完成/博士延展"的评分**无依据，已删除**。
