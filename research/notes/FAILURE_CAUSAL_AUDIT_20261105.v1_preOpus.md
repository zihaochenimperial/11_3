## 0. 先给结论（一页人话）

1. **F0/H2 的失败，主要是"公式/文献可预期"，不是意外。**
   F0 的核心对象 `df_full = df_par + sdf`（总自由度 = 固定结构部分 + 搜索部分）在 Tibshirani（2015）里就是同一个分解：§3 式(15) 定义了 search degrees of freedom（`sdf(f) = df(f̃) − E rank(X_A)`），§5.2 Lemma 5 与式(22) 把总自由度写成"几乎处处光滑部分的散度 + 不连续边界项"，作者明确说第二项"恰好就是 search degrees of freedom"（§5.3）。这是**高斯噪声、线性设计 `f=Xβ̂`、分片绝对连续**设定下的原文结论；我们的是非线性渲染器 + 贪心 birth，这一点原文没有覆盖（所以"所有细节都被预言"不成立），但**"搜索要付出额外自由度、且为正"这一定性结论，以及"用相干随机化估计它"这一做法，文献里早有**。
   H2 被 STOP 的真正原因（Opus 的论证，我复核后同意）是**决策不变性**：风险估计 `R̂(S)=RSS+2σ²df_full−Nσ²` 只依赖总 df，分解后 df_par 与 sdf 在决策里相加抵消——"一个量存在"≠"拆开它会改变任何决定"。这是**设计层面的逻辑缺陷**，不需要实验也能发现，我们是在花了 pilot/Stage-1 的算力之后才由 Opus 门拦下，这是**研究决策错误**（§5），不是实验偶然。
2. **CF0 的失败，主要是"条件性的经验负结果"，部分被理论预期，部分尚无定论。**
   - 被理论**预期**的：信息分配是恒等式（Leiner 等 §2.3：`I_X = I_f + E[I_{g|f}]`；高斯情形下 `1/(1+τ²)+1/(1+τ⁻²)=1`），所以"诚实分裂必然把信息从拟合挪到选择"是定义级事实；"honest/randomized 选择在 K 固定、位置会被后续优化冲掉时收益有限"属于合理预期，但**不是定理**。
   - 经验**观察**：在 D1（过生长）诚实/随机化选择反而 +4~7%（随机化即正则）；在 D3（需要生长）信息丰富的贪心选择明显更好，诚实选择 −3%~−20%，随机选择 −25%。也就是"选择信息有用 vs 选择偏差有害"的权衡依图像类型而翻转。
   - **未定论**：在"接近最优 K"处诚实位置是否有用；真实噪声（非高斯/未知 σ）下是否成立；这些没被采样。
3. **没有发现会使两条 STOP 结论失效的实现或理论错误**（有效性门 V0–V8 全真、重放逐位一致、独立性 |z|<4、单元测试、Opus 三轮更正已并入）。"实验做法的局限"（K=48 固定、R_MAX 截断、合成小图、Adam 混沌）**限定了 STOP 的适用范围，不构成推翻 STOP 的证据**。
4. **为什么大 GPU 不能自动解决**：两次失败都不是算力不足——F0 是"问题设计上被代数抵消"，CF0 是"在被测范围内位置信息不是杠杆，真正的杠杆（K 轴/集成）已被已知方法覆盖"。更大的 GPU 只能让同一问题跑得更快，不会改变"决策只依赖总 df"或"位置被优化冲掉"。
5. **对原创性的含义**：风险估计/选择性推断这条轴在文献里已经很满（SURE、MC-SURE、coupled bootstrap、data fission、search df）。继续在这条轴上做"高斯换皮"，原创度天花板很低。需要的是**换到文献没有直接覆盖的杠杆**（见候选简报）。

## 2. F0 / H2

### 2.1 我们到底在估计什么（公式与假设）
- 模型：`y = x + ε`，`ε ~ N(0, σ² I_N)`，σ 已知（F0 合成实验设 σ₀=0.08，N=4096）。
- 拟合映射 `F: y ↦ x̂`（150 步 Adam × 若干阶段，birth 从候选中按分数选 8 个/轮，共 3 轮，K: 24→48）。
- 协方差自由度（Efron 1986 定义；Tibshirani 2015 式(2)）：`df(F) = σ⁻² Σ_i Cov(F_i(y), y_i)`；乐观度恒等式（同文式(5)）：`E‖y′−F(y)‖² − E‖y−F(y)‖² = 2σ²·df(F)`（y′ 为独立副本）。
- F0 合同 v3 的估计量：从 `y` 做相干随机化 `y± = x + e ± z`（两份独立噪声、方差 2σ₀²，τ=1）；`df_full = Σ_m (F−F̄)·e / ((M−1)·2σ′²)`；冻结结构的支路 `G`（birth 取自独立副本）；`sdf = covariance-df(F−G)`；`df_par = df_full − sdf`；`S=8` 时 birth 候选等于随机，`sdf(8)≡0`。
- 风险估计：`R̂(S) = RSS(S) + 2σ²·df_full(S) − Nσ²`（Mallows/Efron covariance-penalty 型）。

### 2.2 文献里对应的原文位置（L4）
| 我们的对象 | 原文位置（L4，ar5iv 渲染版） | 原文说了什么（我的转述） | 假设/范围 |
|---|---|---|---|
| df 定义与乐观度 | Tibshirani 2015 §1 式(2)；§1.2 式(5) | df=噪声协方差之和/σ²；乐观度=2σ²·df | 只要 `Cov(ε)=σ²I`，不要求高斯（§1.4 说明后文结论多处用高斯） |
| **search df** | 同文 §2.1 式(10)（正交设计的子集选择）；§3 式(15)–(16) 推广到一般过程 | `sdf(f)=df(f̃)−E[rank(X_A)]`，f̃ 为在已选支撑上做最小二乘；§2.1 末："sdf>0 对任意 λ>0 成立"（正交设计、硬阈值） | **线性设计** `f(y)=Xβ̂`；正态误差用于 Lemma 1 与 §5 |
| **总 df = 光滑散度 + 不连续项** | 同文 §5.2 Lemma 5、式(22)；§5.3 | `df = E[Σ ∂f_i/∂y_i] + (边界项：不连续点处 φ·[f₊−f₋] 之和)`；"第二项恰好是 search df"；式(23) 给出正性的充分条件 | 高斯、`f` 分片绝对连续、正则条件(21)；子集选择/relaxed lasso 验证过，**非线性渲染器未验证** |

小结（**事实**）：F0 的 `df_full` 估计量**就是**"Efron 协方差自由度 + 相干随机化（Oliveira 的 CB 构造）"，`sdf` 的**定义思想**（总 df 减去"结构独立选定时的 df"）与 Tibshirani 式(15)同源。
**范围差异（也是事实）**：原文是线性设计+高斯；我们的拟合是非线性渲染器 + 带离散 birth 的贪心非光滑流程。所以"F0 在该设定的数值值"不是被文献直接给出的；被文献覆盖的是**概念、分解结构、定性正性、估计方法族**。

### 2.3 H2 为什么失败：代数抵消 + 已有方法
1. 决策只用 `R̂(S)`，而 `R̂(S)` 只含 `df_full(S)`。`df_full = df_par + sdf` 的拆分在决策里相加抵消。拆分只有在**需要分别知道两部分**时才改变决定（例如 df_par 可用便宜的局部公式、sdf 才需昂贵估计）；我们的估计量两部分同样昂贵（都靠相干随机化），所以拆分不带来成本收益。
2. 整条流程的相干随机化风险估计 = Oliveira 的 CB（已含 SURE 极限与图像去噪实验）。这就是 H2 里 "y-only fission/frozen-leg 估计" 的已有基线。
3. 所以 **H2 as proposed 的"贡献"落在已有方法的特例上**。这是 Opus 在 `OPUS_REVIEW_H1_H2_20261105.md` 给的论证；我现在用 L4 原文把"已有方法"从 L1 升到 L4（Tibshirani §3/§5、Oliveira §1.5/§2.1/§3/§5.3），论证成立。

### 2.4 H1 通过（sdf 显著为正）算不算"意外发现"？
- 定性上**可预期**：Tibshirani §2.1 在正交硬阈值情形证明 sdf>0；§5.3 的式(23)说，只要在每个不连续点"拟合值随该观测增大而增大"，则 sdf>0。我们的贪心 birth 是"数据相关的结构选择"，同类机制。
- 定量上**未被推导**：27.6 df 这个数值、其与图像类型的关系，文献没给；但它是"确认一个已知现象在新设定的量级"，不是新方法。
- **后验发现**（total df 差仅 +8.8，搜索反而降低 df_par 与 oracle 风险）有点反直觉，属于线索，但它依赖已知干净图（evaluator-side），不是估计器结果。

### 2.5 "一个统计量存在" ≠ "分解产生新决策"
这点在 F0 里是**明确的设计错误**：我们把"可以估计 sdf"当成了"可以做新的 birth/停止决策"，没有先问"决策对 sdf 是否敏感"。该错误在 FAIL-0001（F0/H2 STOP）有记录，这里确认其性质：**method-design / originality-gate error，可在纸面推导中提前发现**。

## 3. CF0（交叉拟合 / honest birth 选择）

### 3.1 理论部分（可推导、已被文献含）
- 设 `z ~ N(0,σ²I)`，`y_f = y + τz`，`y_g = y − z/τ`。
  `Var(y_f)=σ²(1+τ²)`，`Var(y_g)=σ²(1+τ⁻²)`，`Cov(y_f,y_g)=Var(y) − Cov(τz, z/τ) = σ² − σ² = 0`；联合高斯 ⇒ **独立**。（Leiner §2.2；Oliveira 式(19)。）
- 信息守恒：每像素 Fisher 信息 `1/σ² = 1/(σ²(1+τ²)) + 1/(σ²(1+τ⁻²))`（因 `1/(1+τ²)+τ²/(1+τ²)=1`）。Leiner §2.3 给出一般恒等式 `I_X = I_f + E[I_{g|f}]`。
  ⇒ **"信息分配代价"是恒等式，不是结论**。"增益不足"或"必然失败"都**不能**由它推出——结论取决于"选择信息的边际价值"与"拟合信息的边际价值"在该任务上的相对大小，这是经验问题。
- 两条路线的命名（沿用 Opus round 6）：XFERg = honest sample splitting（Athey–Imbens 式，L3）；NS = 随机化响应选择（Tian–Taylor 族，L1）；XAVG = 角色互换平均（DML 意义的 cross-fitting，L3）。
- Leiner §6.1（trend filtering）与 Cor.1 **字面做的就是**：用 `f(Y)=Y+τZ` 选结构（knots/基），再用 `g(Y)=Y−Z/τ` 在所选基上回归。XFERg 是它在"高斯 birth 选择"上的对应，只是目标是**估计风险**而非**置信区间覆盖**。

### 3.2 观察到什么（事实；来自 `outputs/CF0-dev-d1/analysis.json`，dev 集 18 图 × 多 seed × 576 单元）

### 3.3 三档分开：观察 / 因果识别 / 猜想
- **观察（有数据）**：见上表。尤其是 `NS ≈ RAWy`（合计），去掉了"信息损失"这一混杂后，诚实位置在该范围内依然不优于贪心 raw。
- **因果识别（部分，有对照的）**：
  - 随机化→正则：D1 上 RANDy、NS(τ↑) 同向变好，随机化集成更好；这与"D1 在 K=48 过生长，随机化起正则/集成作用"一致。有 RANDy/NS/RAWy 三方对照，因果解释比单一对比强，但**没有直接干预实验**（例如固定 K 到 oracle 值再比）。
  - D3：贪心 > NS > 随机，随 τ↑ 单调变差，符合"选择信息有价值，且被噪声稀释"。
- **猜想（无直接证据）**：①"位置会被后续优化冲掉"（漂移 3–4 px 是观察；但"冲掉导致 honest 无收益"是推测）；②"位置不是杠杆，K 才是"——数据支持"在被测范围内 K 轴增益大得多"，但 K 轴的 oracle 被 R_MAX 截断且 RAWcv 用 fission-CV 校准，量级只能作线索。
- **范围声明**：STOP 成立于"固定 K=48 + fission 精度核算 + 本合同"。**未采样"接近最优 K 的 honest 位置"。** 此点 Opus round 8 也指出。

### 3.4 CF0 的结论性质
**条件性的经验负结果**（scientific no-go within scope）。不是公式推翻，也不是实现错误。部分模式（随机化即正则、K 轴、集成）与已知文献方向一致，所以**也不是意外**；真正"没被预言"的只有：在 D3 上 NS 随 τ 单调变差的斜率、以及 D1/D3 的符号翻转，这些是**描述性线索**。

| **R_MAX=4 截断** | D3 在 oracle/CV 下 181/192、167/192 触顶 | 低估 K 轴增益；**不影响 STOP**（STOP 不依赖 RAWcv） |
| **合成小图/有限 seeds** | 3 类图 × 18 图；每类少 | 限定外推；bootstrap 在图像层面，宽度已计入 |
| **实现/理论错误** | V0–V8 全真，重放逐位一致，独立性 |z|<4，单元与分析器测试，Opus round 6–8 更正（STOP 多重性、元数据字段、范围措辞） | **未发现会使结论失效的错误**；曾发现并修复的都在冻结前（FAIL-0010/0011/0012） |

**结论**：没有证据表明 STOP 是由实现/理论错误造成；"问错问题"的风险主要体现在**适用范围窄**（固定 K、合成、已知方差），而不是结果可疑。

## 5. 研究决策层面的错误（引用真实记录）

1. **先验检索停在摘要层**（F0 与 CF0 的 G0）：`G0_reading_log` 中 C14/C15（honest trees）原为 [记忆]，C19/C20 才升到工具摘要级；Ye 1998、Efron 2004、Janson–Fithian–Hastie 在 F0 总结里写成"covers it"，实为 L1。本轮读原文后发现 Tibshirani §5.2–5.3 与 Oliveira §1.5/§5.3 对 H2 的覆盖比摘要所示**更直接**（后者含图像去噪），这一点在 F0 阶段就应被发现，因为它决定是否值得花 pilot。
2. **把通用已知技巧迁移成"候选方法"**：把 data fission / MC-SURE / 协方差罚迁移到高斯 birth，却没有先问"这个迁移带来什么该领域已有方法做不到的新性质"（"高斯换皮"不是贡献）。
3. **机制观察与方法贡献之间缺桥**：F0 的 "sdf>0" 是机制观察，却被当作可立项的方法起点，缺少"拆分如何改变决策"的桥（§2.5）。
4. **小幅阳性后转向**：F3 的 9/12 事后线索（FAIL-0001/0010 记录）促成转向 CF0；该线索是事后、探索性的，转向时已标注"不能当独立确认"，但转向本身说明了**对小阳性的过度追逐风险**。CF0 通过合同+Opus+冻结+独立评估把这一风险限制住了，也因此得到了**干净的负结果**。
5. **好的一面（保留）**：每次都做了冻结、真实 Opus、失败入账、封存确认集；两次 STOP 都是"便宜地失败"，未烧 GPU。

未知项（不当作已证明）：Tian–Taylor、Rasines–Young、R2R、Efron 2004、Ye 1998 原文是否更直接覆盖 CF0 的细节——**待读**（L1）。

## 7. 人话总结

- **F0/H2**：想法本身（"搜索会多花自由度，把它拆出来估计"）在统计文献里已有现成公式和估计方法；我们又把它拆成两块，而决策只用总和，拆开不产生新决策。所以这次失败**基本可以事先从公式和文献推出**，是研究设计上的错，而不是实验运气。
- **CF0**：想法（"用独立副本选位置、在另一份上拟合，可以避免过拟合选择偏差"）也是已知机制（honest 估计、data fission）。我们的实验是干净的，结果是：在固定 K=48、已知方差高斯、合成小图的范围内，诚实选位置没有比朴素贪心更好；真正有效的杠杆是**选 K**和**集成**，但这两项也是已知方法。所以这是**一个有范围限定的经验负结果**，部分合乎预期，部分（近最优 K 处会怎样）还不知道。
- **没有找到会推翻 STOP 的实现/理论错误**。
- **GPU 解决不了**：问题不是算力，而是"问对杠杆"。
- **对下一轮的含义**：不应继续在"风险估计/选择性推断"这条已很满的轴上做高斯移植；应该寻找**文献没有直接覆盖、且能在 CPU 小图上便宜证伪**的机制。候选见 `research/notes/REIDEA_CANDIDATES_20261105.md`。
