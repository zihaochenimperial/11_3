## 0. 共同的建模观察（L4）
GaussianImage（arXiv 2403.08551，摘要与方法节，L4）的渲染是**累加求和**（accumulated summation，无 alpha 排序），每个二维高斯 8–9 个参数（位置、协方差、颜色）。因此图像模型是**对幅度线性、对 (μ,Σ) 非线性**的原子和：`x(u)=Σ_k a_k g(u;θ_k)`，`θ=(μ,s₁,s₂,φ)` 为 5 维原子流形。这使它**精确落入**"连续字典 + 稀疏测度"（BLASSO/off-the-grid）的框架（Denoyelle 等 SFW，式(1) `Φm=∫φ dm`，X⊆ℝ^d 一般域，L4）。这是候选 A、B 的依据，也是它们最近邻的来源。

## 2. 候选 A：凸提升 + 对偶证书的生长/停止（"证书式致密化"）
**痛点（来自我们的数据）**：K 是最大杠杆，但现有两种取法都不令人满意——启发式致密化（梯度/误差阈值，固定预算）没有停止保证；CV/fission-CV 选 K 要额外 ≥2 次拟合且在 2σ₀² 副本上校准有偏（早停）。
**机制与公式**：
- 提升：`min_{m≥0 或有符号测度} ½‖y−Φm‖² + λ|m|(Θ)`，`Φm=∫ g_θ dm(θ)`（SFW 式(36) 同形，L4）。
- 对偶证书：`η_λ(θ)=λ⁻¹⟨g_θ, y−Φm⟩`。KKT：`m` 最优 ⇔ `sup_θ|η_λ(θ)|≤1` 且在支撑上 `|η|=1`（SFW §2/Def.6–7 与 FW 内建停止判据 Algorithm 1 第 3 步，L4）。
- 算法：birth = |η| 的局部极大（用多尺度多朝向匹配滤波经 FFT 求值，再连续精修）→ 幅度凸子问题 → 滑动 (μ,Σ)（非凸）→ 重复；`sup|η|≤1+tol` 停止。λ 通过**纯噪声下 `sup_θ|⟨g̃_θ,w⟩|` 的分位数**校准（g̃ 为尺度归一化原子），使假 birth 率受控；残差结构化时再按需下调。
**该领域最强现有方法做不到什么**：GS 致密化没有"是否已足够"的可检证书；CV 选 K 昂贵且依赖验证划分。证书给出（i）**无需干净图、无需划分**的停止量；（ii）对**任意已拟合高斯集合**可计算的"缺失原子"诊断（证书间隙）。
**方法级差异**：各向异性旋转原子的 5 维流形 + 尺度归一化的上确界校准（look-elsewhere）；λ 路径作为 K 的连续旋钮；证书作为诊断而非仅停止。**不是**：SFW 本身（各向同性/固定核的点源）、MP/OMP（离散字典 + 残差范数停止）。
**贡献假设（仅 proposed，不算已证）**：
- H-A1：校准停止达到 ≥ 50% 的 (oracle−RAWy) 增益，成本 ≤ 1.2 次单拟合当量。
- H-A2：纯噪声图上假 birth 率 ≤ 2α。
- H-A3（条件）：证书间隙与留出风险的 Spearman 相关 ≥ 基线（梯度范数/误差大小）。
计为 1 个方法贡献 + 1 个条件诊断性质。

**最强反驳**：
1. "SFW 换到二维各向异性高斯"——若校准/证书只是复述 SFW，则只剩应用价值，不构成方法贡献。辩护只能来自（a）各向异性尺度归一化校准、（b）证书作 GS 通用诊断、（c）在 CV 基线上的**可复现收益**。
2. 通用阈值保守：Donoho–Johnstone 通用阈值欠拟合，风险最优阈值更低；证书停止的 K 可能系统偏小。这是可测的（K_cert 对 oracle K）。
3. 自然图像不是稀疏高斯和：模型误设使残差结构化，"无缺失原子"永不触发或过早触发。
4. ℓ₁ 收缩偏差需要去偏（relaxed lasso）；支撑选择用的 λ ≠ 风险最优 λ。
5. 非凸"滑动"步使证书只是局部意义。
**廉价杀死实验（CPU/8GB，需新合同+Opus+冻结）**：
- K1 纯噪声校准：200 张纯噪声 64×64，证书阈值下的假 birth 率；>2α → 杀死校准。
- K2 开发集（新图 k≥61、新 seed，**不用 E41–58**）：K_cert 与 oracle-R/RAWcv 对比，风险劣于 RAWy（K=48 raw）的图 ≥ 2/3，或比 RAWcv 差 >10% → 杀死 H-A1。
- K3 成本：证书求值 + 精修 ≤ 1.2× 单拟合当量。
- 独立确认：封存新图 + 新 seed；自然图像来源需另议（allowlist 限制外网）。
**算力与工程**：证书求值 = ~150 个滤波器（6 尺度 × 8 朝向 × 3 长宽比）× FFT，64×64 为毫秒级；一次拟合约数个 CPU 秒量级（据 CF0：约 1.08 万拟合当量在约 131 分钟、≤8 worker 内完成，折合约 6 核·秒/拟合，粗估）；K1–K3 总计约 30–60 核·分钟。大 GPU：仅当扩到 ≥1024² 自然图像批量时才有用，24–36GB 为估算、未实测、不购买；8GB 本机卡多半够 ≤1024²。工程约 1–2 周 AI 编程原型。
**博士延展**：各向异性原子的稳定支撑恢复/最小分离条件；证书用于 3DGS 致密化诊断；与 C 联动（最小分离 ↔ 可辨识性）。

## 3. 候选 C：重参数化不变的投影 Fisher 可辨识性（merge/freeze 的噪声感知准则）
**痛点**：birth 之后没有"该不该合并/冻结"的噪声感知准则；PUP/FisherRF 用对角或二阶近似，会被邻居补偿误导（对角 Fisher 在两个重叠高斯上显示"可辨识"但实际共线）。
**机制**：渲染雅可比 `J=∂Φ/∂θ`（稀疏，局部支撑）。对原子 k 的参数块，取**邻居补偿后的 Schur 补** `I_k = J_kᵀ(I−P_{−k})J_k/σ²`（P_{−k} 为其余原子切空间投影）；在**重建空间**（而非参数空间）度量，故对单位/参数化（Cholesky vs 旋转缩放）不变；最小特征值方向 = 该原子最不可辨识的变形（如拉长、旋转），其标准差 ≈ `(λ_min)^{-1/2}`。决策：若不可辨识方向的预测标准差 > 阈值（如 > 半个像素/半个尺度）则冻结该方向或与邻居合并。
**最强现有方法做不到什么**：对角 Fisher 剪枝不处理邻居补偿与参数化依赖；MML 成分湮灭（Figueiredo–Jain，L1）按似然证据，不给出重建空间的方向性可辨识信息。
**贡献假设**：H-C1：预测方差与噪声重复下的 MLE 经验方差之比在 [0.5, 2]（局部制度，warm start 自真值）；H-C2：按该准则合并后，在相同总 K 下留出风险不劣于基线（梯度/不透明度剪枝）。
**最近邻**：PUP-3DGS（2406.10219，L2 经 digest：二阶重建误差剪枝）、FisherRF（L2）、Feng–Kao 2026（2602.09415，L2 经 digest：算子级可辨识性）、显微镜 CRB（Ober–Ram–Ward，L1）、Papantonakis（L2）。**均未读正文**。
**最强反驳**：CRB 对高斯 blob 经典；曲率高≠值得扩容（近似偏差）；局部线性制度外无效；Adam 混沌使"拟合值"本身不稳（需用 warm start 解析）。
**杀死实验**：K-C1：对 3 类合成图各 12 张，噪声重复 M=200，warm start 自真值，经验协方差 vs `(JᵀJ/σ²)⁻¹` Schur 块，比值超出 [0.5,2] 的原子比例 >30% → 杀死 H-C1。几乎零成本（雅可比解析）。
**算力/工程**：纯 CPU；3–5 天；无 GPU 需求。**博士延展**：与 A 的最小分离联合给出"可恢复 vs 不可恢复"相图。

## 4. 候选 B / D / E（简）
- **B 极值显著性**：把 A 的阈值/ λ 用 Kac–Rice（Taylor–Loftus–Tibshirani，1308.3020，L4：任意光滑高斯过程极大值的有限样本 p 值，Gaussian 误差）或 Euler 特征（Siegmund–Worsley 1995，L2）解析给出，序贯 spacing。**最强反驳**：核心统计工具已存在，残差在联合精修后非白；**杀死**：解析 vs 模拟的上确界分位数偏差 >20%。独立贡献弱，作 A 的部件。
- **D 空间自适应容量**：区域级 fission 验证。**最强反驳**：Lepski/AWS/SureShrink 空间自适应先验、VGNC 全局版；**杀死**：混合平滑/纹理合成图上区域级 vs 全局 CV 选 K，增益 <2% 即杀。增量工作。
- **E 间接率失真**：噪声输入下的 K(σ,R)；Wolf–Ziv 分离原理使 MSE 下"先去噪再编码"最优，独立贡献小；**杀死**：K 随 σ 的最优位移与理论预测不符/无收益。

## 5. 对"不降低贡献度目标"的诚实评估
- 没有任何候选达到"有把握的高原创度"。A 的方法骨架（贪心加点 + 联合精修 + 证书）是 SFW/MP 的成熟范式，原创空间集中在：各向异性图像原子的尺度归一化校准、GS 通用证书诊断、以及在 CV 基线上的真实收益。若 K1–K3 失败，则 A 作为"原创方法"即被否决，**降级不是自动的**——应转向缩窄问题（例如只保留证书作为诊断性质并重做近邻核验）或换候选，由 Opus 与真人决定，不预先承诺。
- C 的 CPU 证伪最干净，且与 A 构成"birth 侧/merge 侧"互补，但单独贡献偏条件。
