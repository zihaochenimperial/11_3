# AS 方向决策备忘 (给真人; 2026-11-06; proposed, 0 个已验证贡献)

状态: 这是决策备忘, 不是实验证据。依据: S2 机械判定 STOP-Q1 (FAIL-0024)、G0 第二轮近邻检查 (G0 阅读日志 C68-C71, 均 L2-L3)、真实 Opus 方向咨询 (run 20261106T045933Z-opus-review-f652, 自报 claude-opus-5-5; 全文 research/notes/OPUS_REVIEW_AS_DIRECTION_20261106.md)。

## 1. 现状一句话
S2 否决了"补偿感知联合评分 JOINT 优于便宜规则"和"生长优于固定 K"(仅限 32x32 程序合成基准与该合同)。事后观察 (数据拟合贪心不如随机、余量只在看干净图选时存在) 与已发表/已停止的结论同类, 不构成新贡献。

## 2. 为什么不推荐 A / B (Opus 裁决: 驳回)
- A (风险估计/搜索代价校正/留出停止): 就是已停止的 F0/H2 (搜索自由度) + CF0 的 RAWcv (留出停止比固定 K 好 33%) 换名; 已被 Ye 1998、Efron 2004、Tibshirani 2015、arXiv 2308.13630 (msdf)、OMP-CV (1602.06373)、data fission 覆盖。做 A 等于复活被硬规则禁止的旧线。
- B (数据拟合贪心 vs 随机): 被 arXiv 2506.15643 (随机化前向选择) 及 CF0 自己的"随机化即正则化"怀疑覆盖; 教科书现象。
- 唯一未被点名覆盖的部分: 连续几何 Gaussian + 每个候选做非线性 LM 回拟 + 病态模糊算子。Opus 认为这是领域迁移的"基准价值", 不是机制创新, 不能称贡献。

## 3. Opus 指出的最大风险 (未经检验, 需要你知道)
32x32 图上 K_max=36 约 250 个连续参数对 1024 个带噪像素、没有任何停止/正则: 任何拟合得更差的规则 (RAND/JOINT_FREE/FIXED-K) 都显得更好; ORACLE_xs 的 45% Gate-0 余量可能只是"干净图 oracle 拒绝拟合噪声", 任何留出停止规则也能拿到, 并不是"选哪个编辑"的余量。若如此, Gate 0 的 PASS 本身设定有误, F0 -> CF0 -> AS 三条主线是同一个已知现象 (贪心过拟合, 被留出停止治愈) 的三次重新发现。次要风险: ORACLE_y-full 仅 6 单元、ORACLE_ys 96 单元只是轶事; 剂量-响应非单调与 INIT-N 空诊断未解释; 程序合成的团块图可能偏向 Gaussian。

## 4. 选项 (请你选; 在你回复之前我不启动任何实验)
- **C. 停止本主线 (Opus 推荐)**: 保留全部负结果记录和失败日志, 不再开新实验; 等你决定新主线或结束项目。
- **D-headroom. 公平停止下的余量复核 (仅为基准, 创新声明 = 0)**: 假设: 在全新程序图上, 所有臂都用同一个预注册留出/fission 停止准则 (无固定 K_max 终点), ORACLE_xs 仍比最好的非 oracle 规则 (BLOCK/RAND/OMP/JOINT 之最小) 低 >= 10% 几何均值 MSE。杀死准则: 余量 < 10% 或成对符号翻转置信区间含 0 -> "选哪个编辑"这条轴在此任务上关闭。成本约 S2 或更低 (CPU)。预期信息主要是关闭这条轴; 通过后下一问就是 A, 又撞车。需要你批准 (新图/新合同/真实 Opus/冻结)。
- **D-rescope. 改任务与基线**: 现有结果显示强模糊下 Tikhonov (GCV) 比最好 Gaussian 高 3.4-6.2 dB, 但 Gaussian 臂本来就没有正则化; 公平比较需要"带显式幅度/平滑惩罚或留出停止的 Gaussian" + TV 基线 + 可能不同内容/退化。这是新主线, 只能你批准; 贡献概率同样低。
