# P1817 博士方向：Claude + ResearchRabbit 原创性与可实现性审查

2026-11-05。性质：文献观察、理论候选和研究设计；不是已证明原创、已完成新方法实验或正式选择的新合同。

## 结论

值得投入一个有边界的理论/机制验证阶段。目前有一项更清楚的主贡献候选和两条有条件的博士扩展，尚未构成三项独立成果。能实现代码、能获得稳定收益、具有足够原创价值，是三个不同的判断。

推荐优先验证的问题：在最终高斯数量和计算预算相同的条件下，候选搜索与自适应生长引入了多少额外拟合风险；能否在不知道干净图的情况下，估计这部分风险并改善 birth/冻结/停止决策？这是待验证的问题，不是已观测到的缺陷。

## 已有工作排除了哪些宽泛表述

| 宽泛想法 | 最近邻及含义 |
|---|---|
| Fisher 信息用于高斯表示 | FisherRF 已做信息量与不确定性决策；PUP 已做二阶空间敏感度剪枝。因此不能将公式或二阶分数本身当创新。[1,2] |
| 高斯可辨识性与稳定性理论 | Feng/Kao 已提出相关算子级分析。必须逐条比较假设、表示和定理，而非靠换成2D命名原创。[3] |
| 每个高斯不同复杂度 | Papantonakis 已自适应选择逐高斯 SH 系数。因此泛称“自适应自由度”不够。[4] |
| 贝叶斯高斯、不确定性、复杂度联合 | Jia 等已提出 NIW 几何后验、复杂度信号和区间校准。我们的差异必须落在具体决策、估计方法和证据上。[5] |
| 用有效自由度/SURE 解决单图去噪过拟合 | Jo 等 ICCV2021 已做 DIP 自由度分析与停止准则；MC-SURE 和 search df 更早已有。简单移植到高斯不足以自动成立为博士贡献。[6–8] |

## 可以形成什么贡献

**A：自适应原语生长的搜索风险估计与决策。** 实现路径清楚：比较冻结拓扑的局部自由度近似、全流程扰动风险估计、独立噪声重复下的协方差参考值；再控制候选数、birth数和冻结策略。真正需要增加的新内容可能是对非光滑生长有效的估计/校正、显著更低成本的算法或明确的新适用边界。全流程 MC-SURE 本身是已有方法，必须作为强基线。若直接移植就同样有效，则应缩小原创声明，不能靠改名坚持新颖。

**B：退化观测下的几何自由度解锁理论。** 理论目标是预测位置/尺度何时无法从观测中可靠区分，考虑邻居补偿和归一化表示，再指导冻结。局部 Fisher 对角块可能误判；分数还应处理单位变化和表示对称性。实现估计器可行，但正确的非平凡定理难度明显高于代码；目前属于条件扩展。

**C：观测支持范围内的可靠性。** 目标可收窄为在明确噪声与算子假设下，对可估计图像量给出经独立图像验证的区间与失效检测。单图的不可观测零空间成分，没有额外先验或数据不能普遍校准。是否成为独立贡献取决于相对已有贝叶斯/Laplace方法的新能力；暂不算第三篇论文。

一个论文可以包含分析、估计器和决策算法等多个贡献点；这不等于已获得三个互相独立的博士成果。

## 最便宜且有决定性的验证

1. CPU小图：固定表示、优化预算和最终K，改变候选搜索规模，用多次独立噪声实现估计风险与参考自由度。验证候选搜索是否产生值得处理的额外风险，同时区分噪声与优化随机性。干净图只在独立评估路径使用。
2. 同一表示下比较：固定K、残差生长、全局K选择、直接移植全流程MC-SURE/DF早停、拟议校正。若强基线已经解决问题，不把移植本身称为原创算法。所有扰动/搜索/选择开销计入总时间。
3. 对可辨识性做复制分裂、邻居补偿、换坐标单位的反例验证。先检验度量是否可信，再决定是否用于优化。
4. 有机制余量后才冻结开发选择，在未用于选择的自然图像、多噪声水平与多个seed上确认。去模糊/SR扩展须重新界定测量噪声、风险估计对象与零空间边界。

这些是前瞻设计，尚未执行或正式冻结。现有 holdout-birth pilot 的合同与 NO LAUNCH 状态保留；此审查不替代其修复。

## 算力与可实现性判断

CPU/本机8GB适合首先做小图反证与机制试验。24–36GB单卡是后续2D多图/多算子验证的合理目标；当前没有实测峰值支持精确显存承诺。避免稠密全Jacobian/Fisher，采用局部块或矩阵向量运算。不能把独立seed并行全部塞入显存当作必要条件；本项目仍一次最多一个GPU实验。

晋级贡献须同时满足：最近邻方法级差异可说明；核心失效机制可重复；新估计/规则在假设内经参考实验验证；相同总预算下对强基线有可重复收益或给出有价值的能力边界。没有实验前不承诺正结果、分数、论文数量或原创百分比。
