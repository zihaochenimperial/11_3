# P1817 pilot amendment: shared prefix and measured nondeterminism

Date: 2026-11-05. This is a prospective amendment to `P1817_HOLDOUT_BIRTH_PILOT_CONTRACT_20261104.md`, before any pilot output exists. Original input, seeds, masks, selection rule, loss, Gaussian counts, split boundaries and all other controls remain in force. Classification remains auxiliary/development. The existing draft is NO LAUNCH until the amended implementation, evaluator and independent audit pass.

## Why the amendment is necessary

Both Codex and Claude's read-only audits found that independent same-seed GPU runs cannot guarantee the same step-500 pool because the upstream backward kernel uses floating-point atomic additions. Therefore the original requirement of identical final hashes across independent full runs may reject a leakage-free implementation for nondeterminism and does not ensure matched candidate pools. This is a methodological correction, not a response to pilot results.

## Frozen changes

1. Execute steps 1–500 once using A data only. Save the full model parameters and the A-derived ordered candidate pool, candidate attributes and all relevant RNG states before choosing candidates. Record hashes. Fork control and holdout from that identical saved prefix and pool. The first 64 and B-ranked 64 rules are unchanged. Adam is re-created at the birth event for every arm, matching the original birth path: pinned upstream `model.py` `_add_gaussians` creates a new Adam optimizer after appending the Gaussians.
2. Replace exact full-trajectory hash equality as the sole C-invariance test with: (a) CPU exact equality of all training/selection inputs derived from A/B after a C-only perturbation, (b) load the same saved prefix and pool and check their hashes, then recompute candidate scores/selection under both C inputs and require exact equality, provided repeated forward-only computations have first been shown bitwise stable on the execution device, and (c) measure full-run variation from exactly two same-input control continuations from the shared prefix. Do not attribute GPU variation to leakage without this baseline. C input must be discarded from trainer-side tensors before initialization; only the separate evaluator may read C.
3. Run exactly two control continuations and one holdout continuation from the same saved prefix and pool. For C-fold noisy MSE and clean C-fold MSE separately, define the control noise floor as the absolute difference between the two controls. Define the holdout improvement as mean(control MSEs) minus holdout MSE. A preliminary pass requires both improvements strictly positive and each strictly larger than its corresponding control noise floor, plus all split, provenance and matched-prefix checks. A complete valid comparison that fails any improvement criterion is no-go; missing runs, measurement failures or unverified assumptions are inconclusive and cannot pass. Data leakage or violated matching invalidates the run. Two control repeats give only a minimal observed floor, not a statistical confidence interval, and do not estimate holdout variance. Report all per-run values and the decision without changing these rules after seeing results.
4. Selection B MSE may be reported descriptively but cannot decide success. Clean truth is evaluator-only on this development image; C is not used for proposal, tuning or stopping. Report the common-prefix wall time once, each arm's continuation and selection time separately, and the total actual campaign time with the prefix counted once. For a standalone per-arm cost comparison also report the common prefix plus that arm's own work, explicitly labeled as counterfactual standalone cost. Do not claim matched wall time when unequal.

## Gate before GPU work

Commit the amended contract and evaluator before generating pilot outputs. CPU-test partition integrity and C isolation, scorer finite handling, saved-prefix/pool validation and failure paths. Independently review code and evaluator. Before any GPU pilot, serially check idle GPU and a single-runner lock, verify forward-only reproducibility and establish a bounded control-repeat path. If those checks fail, stop and document; do not silently relax equality or discard failures.
