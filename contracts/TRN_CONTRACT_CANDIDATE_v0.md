## 0. 研究问题与主张边界
固定数量 K 的 2D Gaussian, 已知核 A, 持续图像正则目标 F_a 不变 (与 GEO 同, 见 §1)。问题: 在 Gauss–Newton/LM 外层迭代之间, 内层线性化问题的**有效求解子空间**能否被 (i) 便宜地跨步输运、(ii) 用少量学习修补补齐剩余耦合, 使**同等画质与目标**下的端到端成本下降?
主张只可能是: "在预注册条件下, 方法 X 相对最强确定性对照 Y 的端到端工作量/墙钟净比为 R (CI), 画质与目标等价"。**不**主张: 通用性、原创性、全空间谱界。
三个分开的问题 (沿用 GEO-3 做法): Q-A 成本结构 (Amdahl: 迭代部分占多少); Q-B 子空间输运的**同状态**价值 (含理想上界); Q-C 闭环端到端净收益。学习修补 (TRN-5) 只有 Q-B 的 G-B 与 G-D 通过后才开启。

## 1. 固定对象 (继承, 不改)
- 目标: F_a(θ) = 1/(2σ²)||y − A x(θ)||² + a/2 ||x||², x_ref=0, a = lam/σ², x(θ)=Σ_k w_k exp(-½(u−m_k)ᵀΣ_k⁻¹(u−m_k)), Σ=LLᵀ, θ_k=(w,mx,my,l11,l21,l22), K 固定。算子 A = B⊗B (可分离反射边界高斯模糊, 已知)。数值代码 src/geo_core.py (冻结, sha e92732df…15fbc4, 只读 import; 见 contracts/GEO_K1_FREEZE_RECORD.txt), src/geo_flops.py (冻结 076a0a61…bd7d)。新代码只放 src/trn_*.py、experiments/trn_*.py、tests/test_trn_*.py, 不改任何冻结文件。
- 条件: C1–C4 = (sb,σ) ∈ {(1,0.01),(1,0.03),(2,0.01),(2,0.03)}。主 lam = 1e-3; 敏感性 lam ∈ {1e-5, 1e-2} (仅 dev, 不入闸门)。
- 内层线性化问题 (状态 θ_t, 阻尼 κ): η=κ·Λ_A, Λ_A=‖A‖₂⁴/σ²; M_t = [ A J_t/σ ; √(a+η) J_t ]; H_t = M_tᵀ M_t = J_tᵀ(AᵀA/σ² + (a+η)I)J_t; g_t = J_tᵀ(Aᵀ r/σ² − a x); 二次模型增益 Δq(δ) = gᵀδ − ½δᵀHδ。受界活动集 (ε-active, geo_core.bound_active) 上的参数在 H,g 中冻结 (限制到自由坐标), 活动比例 >10% 的状态标记并单独报告。H 在自由坐标上可能秩亏: 一律在投影/增广最小二乘意义下处理, 用 H† 而非假设 SPD。
- 恒等式 (标准, 非新结果): ‖J e‖ ≤ ‖M e‖/√(a+η); ‖M e‖² = r_cᵀ H† r_c (相容残差)。
- 步接受/回溯/κ 规则沿用 geo_core._accept/_finish 原样 (冻结), 所有闭环 arm 共用同一接受器 (公平性)。

## 4. 内层求解器接口与 arm 集 (同状态研究; 全部在同一内层问题 (H_t,g_t) 上)
统一求解器: 带紧缩的 Jacobi 预条件 CG (deflated PCG), 预条件 P_J = diag(JᵀJ)⁻¹ (无需 A-施加, 与冻结 PCG8P 同类); 敏感性: P_H = diag(H)⁻¹ (需 p 次 A-施加, 严格记账)。秩预算 k ∈ {8,16,32} (总秩, 含修补)。
- D0 plain PCG (无子空间); D0b PCG + 6×6 Gaussian 块 Jacobi (块由 AJ 列组构建, **构建成本严格记入**) — 最强"无子空间"确定性对照。
- D1 oracle-fresh-λ: 当前 H_t 最小 k 个特征向量 (经典紧缩, 成本 0, 上界诊断)。D1e oracle-effective: 按能量 e_i=(v_iᵀg)²/λ_i 取前 k 个 (真正影响当前解的方向; 与"参数冗余"区分: 报告 95% 能量所需秩 r_eff 与最小 k 特征向量的能量捕获率)。
- D2 坐标/Ritz 回收: 上一状态末端的 k 个 Ritz 向量 (来自 t−1 的实际 CG 谐波/普通 Ritz 提取, 成本计入) 原样用于 t, 并在 H_t 下做 Rayleigh–Ritz (k 次 H_t 乘积, 计入)。
- D3 确定性输运: Y = M_{t−1}U_{t−1}; U'=argmin_Z‖M_t Z − Y‖_F (M 度量下的 LS 回拉), 再 Rayleigh–Ritz。两个版本: **D3x** (LS 精确解, 成本不计, 诊断映射质量) 与 **D3p** (Jacobi-PCG 解 LS, 固定 n_tr∈{3,5,8} 次迭代, 成本全计)。
- D4 理想输运: 与 D3x 相同的映射但起点是 t−1 的**精确**有效子空间 (D1e 于 t−1), 成本不计 — 隔离"提取不完美"与"映射不完美"。
- D5 新鲜修补基线 (非学习, 成本计入): 在 D3p 基上追加 r 个由当前残差的短 Krylov/Lanczos 扩展得到的向量, 总秩=k (k_t=k−r, r∈{2,4,8})。**这是学习修补必须打败的真实竞争者**。
- D6 理想修补 (oracle 上界, 成本 0): D3p 基 (k_t=k−r) 之上追加 r 个 oracle 向量 = 补空间中剩余误差 δ*−P_Uδ* 能量最大的 H-本征方向。注: D6 是 oracle 上界, 学习模型看不到该信息; **不得**把 D6 当作可达基线, 只用于 G-D 的余量判断。
- 所有 arm 报告: 达到准则的迭代数、工作量 W (含建立/提取/输运/投影/RR)、峰值内存。

## 5. 同状态准则、记账、统计
- 同质量准则 (oracle 停止): 迭代至 ‖e_k‖_H² ≤ ρ‖δ*‖_H², ρ∈{1e-2,1e-4} (等价于预测增益达 (1−ρ)Δq(δ*))。实用停止: 相对残差 ≤ ε_r ∈ {1e-1,1e-2,1e-3}, 同时报告达到的 ρ 值。迭代上限 safety=p。
- 工作量 W: 沿用 geo_flops 公式; 新增公式写入 src/trn_flops.py (在任何分账前冻结 sha): 子空间提取、LS 输运迭代、Rayleigh–Ritz (k 次 H 乘积 + k³ 小特征分解)、QR(p×k)、投影 (O(pk) 每迭代)、Lanczos 扩展、块 Jacobi 构建 (6K 次 A-施加)。H 乘积 = J 乘 + A + Aᵀ + Jᵀ 乘 (与 geo_core._iter_pcg 的 matvec 同口径)。
- **分账 (Q-A)**: 每个外层迭代分解为 c_jac(渲染+Jacobian 构建)、c_rhs(梯度)、c_setup(提取/输运/QR/RR/块构建)、c_iter(CG 矩阵乘+投影)、c_acc(渲染+F+回溯)。f_iter = c_iter/(总); 同时用 CPU 单线程墙钟 (min-of-3, 同机, 记录机器与 BLAS 线程=1)。闸门以 W 为准, 墙钟方向须一致 (沿用 K1 做法)。
- 统计: 单元 = (图像, 条件, 规模) 轨迹; 以图像为簇, 配对 (同状态同 arm 间) 比较; 报告中位数比与图像簇自助法 95% CI; 强闸门看 CI 下界。多重比较: 只有 §7 列出的预注册读数入闸门, 其余为描述性。

## 6. 闭环 (Q-C; 仅在 §7 的 G-A、G-B 通过之后运行)
- 管线: 外层 GEO 接受器同上; 内层 = 候选 arm (D0b 作为最强 matrix-free 基线, D2, D3p 管线, D5 管线); 每个 arm 在 dev 上用小网格调 (κ0∈{1e-3,1e-2}, f∈{3,10}, k, n_tr, ε_r) — 每 arm 同等网格大小与调参预算 (公平性)。
- 画质与目标等价: 运行至 F ≤ F_ref_final·(1+1e-3) (F_ref_final 取精确 GEO 参考轨迹的末值), 并要求 PSNR 与参考之差 ≤ 0.05 dB (仅评测侧计算); 未达到者按 safety 删失并如实报告 (不静默丢弃)。成本 = 首次达到时的累计 W 与墙钟。
- 报告: 冷启动端到端 W 与墙钟 (一个外层 GEO 全轨迹)、迭代摊销 (每外层迭代内层 CG 迭代数)、峰值内存、失效率 (no_step、秩突变、被拒回溯)。训练成本 (TRN-5) 单列, 不摊入单图成本。

## 7. 预注册闸门与分支 (候选阈值; 待 Opus 审定; dev 校准后在冻结前固定)
- **G-A (Amdahl, dev)**: 在 M 与 L 上, D0b 管线的 f_iter 中位数 ≥ 0.5 且每外层内层 CG 迭代数中位数 ≥ 10 → 输运有结构上的空间; 否则 (或 f_iter<0.3) → **转测量压缩路线 (MC 合同, §9)**。理想加速上界 S_max=1/(1−f_iter) 报告。
- **G-B (理想余量, dev→confirm 同判据)**: D4+D6 (k_t+r=k) 相对 D0b 的 W 比的中位数 ≥ 1.5 (CI 下界 ≥ 1.3), 在 M 与 L 均成立 (k 取使该比最大者前须在 dev 上冻结 k, 不事后选); 否则 → 转 MC 路线 (无输运余量)。
- **G-C (确定性输运价值)**: D3p 管线相对 max(D0b, D2) 的 W 比中位数 ≥ 1.2 (CI 下界 >1.0) → "确定性输运本身有用" (可独立成果, 无需学习)。
- **G-D (学习余量)**: 同时满足 (i) D6 相对 D3p 的 W 节省 ≥ 20%; (ii) D5 (非学习修补) 的节省 < D6 节省的 50%; 否则不启动网络 (D3p/D5 即结论)。
- **G-E (闭环)**: 见 §6; TRN-5 网络的合同附录须预先定义"相对最强确定性对照 ≥20% 净收益 (含推理+检查+投影+训练摊销之外的全部在线成本) 且在 held-out 图像与 held-out 核族上不劣于 D5"。
- 任一闸门失败: 如实写 FAILURES (类别=INCONCLUSIVE/NEGATIVE, 不改写), 按上述分支转 MC 或停止, 不调阈值、不重跑已完成阶段、不放宽配置。
- 秩突变/边界/退化: 每状态记录 (a) 活动集比例, (b) 数值秩 (H 谱 rcond 1e-12)、(c) 近重合原语对数 (间距<0.5σ_A 有效宽)。输运在秩跳变状态强制回退到 D0b (确定性回退), 回退率报告; 回退状态**计入**分母 (不选择性剔除)。

## 9. 测量压缩 (MC) 备选路线 — 触发规则与最小对照 (定义在本合同, 细节待 MC 附录)
触发: G-A 失败, 或 G-A 通过但 G-B 失败。对象: 在保持精确 F_a 接受检查的前提下, 压缩 Jacobian/Hessian 的**测量侧**访问 (行/列采样、局部块、随机或学习 sketch), 比较: 精确 AJ、随机子采样/Newton sketch、解析/层次局部近似、learned Hessian sketch (文献近邻, 见 G0 C84+)。成本计入全部访问原算子次数; 同样的画质/目标等价判据与 confirm 边界。MC 附录同样须经 Opus 并先冻结。
