## 0. 近邻与新颖性
读取深度见 research/notes/G0_reading_log_CA_20261109.md (只有 BUQO 为全文; 其余为摘要/方法段或经 Codex 核对, 已逐条声明)。本节点不主张任何方法新颖性: 组歧义的"一个亮源 vs 两个暗源"问题是 PCAT 的原始动机; "给出反例图/局部不确定"是 BUQO; 范围/零空间分解与噪声修正是 DDNM; 剖面似然/邻居重优化是 Raue 等的经典构件; 物理分量加学习残差是 López-Tapia 等。CA 只回答一个内部问题: **JR 终态 (FAIL-0035) 中聚焦臂 OBS-J 的重建质量缺口, 在噪声与表示误差两个因子上归因到哪里**, 其结果决定下一机制是否有依据。

## 1. 待归因的观测 (JR 终态, 不重跑)
JR VERIFY (12 图 × 4 核, 384 次运行, 冻结规则判 STOP): OBS-J 的 Q-AUC (对干净图的 PSNR 均值) 23.54 dB, 低于 RND-J 24.40 (dQ −0.85, BCa 下界 −1.07, OBS-J 胜 1/12)、OBS-I 24.00 (dQ −0.46)、IND1 23.82 (dQ −0.27); 在目标函数 F 口径上 OBS-J 反而更好 (dO −0.27/−0.31/−0.13); 所有臂 PSNR 先升后降 (OBS-J 峰值 24.55 → 终点 22.80)。JR 图近乎可被 K=36 个 Gaussian 精确表示 (设计干跑中 33–51 dB, 见 outputs/CA/scratch), 且噪声 σ=0.02 恒在。因此 JR 无法区分: (N) 噪声被联合修复吸收得更快; (R) 表示误差; (OPT) 与二者无关的分组/优化效率差; (CFG) 固定调参协议的产物。CA 通过 2×2 配对析因直接分离 N 与 R, 并用共同固定配置 + JR 调参配置两个块区分 OPT 与 CFG。

## 2. 设计: 噪声 × 表示 的 2×2 配对析因
- **单位 = 基底图 (base image), n=16** (CONFIRM 811–826); 每个基底图 × 4 个已知核 (G15、AG、MO、DK; 与 JR 同定义, src/jr_op.py 精确稀疏算子) × 4 个格 × 臂。统计单位取基底图 (4 个核上的均值), 核维度为固定设计因子, 逐核结果只作描述。
- **表示因子**: R1 = 锐利的非 Gaussian 结构 tile x_s (ca_gen.sharp_image, 四个族: 阶跃/多边形碎片、光栅×包络、成对细线、边+光栅; 复杂度层 hi)。R0 = x_s 的 K=36 Gaussian 投影 x_G (ca_gen.kfit: 3 个网格起点 + 5 个质量加权随机起点的强多起点单原语 Gauss–Newton, 同引擎同目标, A=I, 岭 0; 取最优起点)。x_G 由 K=36 个 Gaussian 渲染得到, 对 K=36 的模型**逐元精确可表示** (单测核查); 模型类与引擎一致, 权重带符号 (DEV 拟合里 0–7 个/图为负权重), 故 R0 可含负权重 Gaussian (这属于"同一模型类的精确表示", 不是缺陷); R1 的实际表示误差以 x_s 对 x_G 的 PSNR 报告 (psnr_rep; 这是对"最优 K=36 近似误差"的上界估计, 起点间散布一并记录)。hi 层目标 psnr_rep 约 27–35 dB (CAL 校准 §15); R0 与 R1 以投影配对: 质量、整体布局、峰值相同, 边宽/高频含量不同 → 该差异本身是表示因子的一部分, 并以匹配报告披露 (梯度能量比、拉普拉斯能量比, §5)。
- **噪声因子**: 有噪 y = A x + ε, ε = SN·ξ, SN=0.02, ξ 由 (标签 31, 图, 核) 播种, **同一 ε 用于 R0 与 R1 的同图同核**; 无噪 y = A x (ε=0)。无噪格**保留相同的数值尺度 SN 与同一正则比 a=1e-3/SN²**, 不除以 0, 仅去掉噪声项 (单测核查 JProb 的唯一构造点)。
- 格: (R0,free) (R0,noisy) (R1,free) (R1,noisy)。同一初值 θ0 = GC.grid_init (对各格的 y 的最小二乘幅度), 各臂同一初值。
- 评测对象: 各格自己的真值 (R0 格对 x_G, R1 格对 x_s) 的 PSNR; 同时记录对 x_G 的 PSNR (R1 格, "相对投影")、对无噪模糊图 A x_true 的误差、边缘区域 PSNR。

## 5. 指标 (评测侧, 对各格自己的真值; 判定只用 Q-AUC)
- **主指标 Q-AUC** = 冻结工作网格 GRID=geomspace(1e9, 3e10, 8) 上 PSNR 的均值 (每个网格点取 W ≤ 网格值的最后一次记录状态; 预算以 flop 代理 W 计, 含分组构建)。PSNR 峰值为 1 (图像峰值归一)。
- **机制/辅助指标 (不参与判定, 仅作机制诊断, 证据层级见 §8)**: 峰值 PSNR 与终点 PSNR; 边缘区域 PSNR (真值梯度模前 25% 区域 3×3 膨胀); 数据空间误差 Qblur = A x̂ 对无噪模糊图 A x_true 的 PSNR; (R1 格) 对投影 x_G 的 PSNR; 残差比 ρ = ‖y − A x̂‖²/(SN² m) 以及匹配数据拟合处的 PSNR Qfit_τ (首个 ρ ≤ τ 的网格状态, τ=4,1, 未达为缺失); 噪声吸收比 nf = ⟨A x̂ − A x_true, ε⟩/‖ε‖² (仅评测用, 有噪格); 表示失配吸收比 mf = ⟨A x̂ − A x_G, A(x_s − x_G)⟩/‖A(x_s − x_G)‖² (R1 格); O-AUC (目标函数间隙 log10 归一, F_ref = 同题各臂访问到的最小 F); 拒绝率; 墙钟; 工作量。
- **匹配报告 (描述性)**: R0 对 R1 的质量比、峰值、梯度能量比、拉普拉斯能量比 (每图), psnr_rep 的分布。R0 比 R1 更平滑是构造的结果, 属于表示因子的一部分, 不作为"匹配"来宣称。

## 6. 统计 (预注册; 判定一次读取后不再改)
- 间隙 G_b(格, 对照) = Q(OBS-J) − Q(对照), 单位 dB, 取每个基底图在 4 个核上的均值; 主对照 **RND-J**; IND1、OBS-I、SPA-J 作并列次对照 (各自独立判定, 不合并, 不取"最强"事后选择)。
- 标签 (δ_D = 0.25 dB, 小于 JR 中最小的 OBS-J 缺口 0.27 dB): 每格以 BCa (B=10000, 种子 20261109, trn_same_state_reduce.bca, 单侧 95% = 双侧 90%) 给出均值的上下界; **D (有缺口)** 当上界 < −δ_D; **E (无实质缺口)** 当下界 > −δ_D; 否则 **I (不确定)**。
- 对比 (均对基底图配对): N_effect = ½[(G(R0,noisy) − G(R0,free)) + (G(R1,noisy) − G(R1,free))]; R_effect = ½[(G(R1,noisy) − G(R0,noisy)) + (G(R1,free) − G(R0,free))]; **I_interaction** = [G(R1,noisy) − G(R0,noisy)] − [G(R1,free) − G(R0,free)] (方法缺口的"噪声 × 表示"交互)。每个对比报告均值、BCa 上下界、SD、**MDE80 = (1.645 + 0.8416)·SD/√n** (按观测 SD 事后计算, 同时给出 DEV 先导的先验估计, §15)。
- 多重性: 判定是对四格标签的一条固定组合规则, 不做逐格校正; D 的声称要求单侧 95% 上界 < −δ_D, 而 STRONG 要求多个格同时标 E, 其联合假阳性率高于单个 95% 界, 这一点在终态报告中披露。n=16 图的功效有限 (§14)。
- 分解对 (描述性, 无判定): Q-AUC 缺口 RND-J−IND1 (联合更新 vs 独立更新, 与分组规则无关)、SPA-J−RND-J、OBS-I−IND1、OBS-J−SPA-J 的四格均值与 BCa 界及噪声主效应/交互, 用于看 "噪声交互" 是联合更新本身 (与分组规则无关) 还是观测混淆分组特有的; OBS-J−IND1 = (OBS-J−RND-J) + (RND-J−IND1)。
- 次要分析 (描述性, 不改判): 逐核逐图明细; 表示误差剂量响应 (R_effect 的每图值对 −psnr_rep 的 Spearman); 块 S 的并列判定; 三个次对照的并列判定。

## 7. 预注册原因判定表 (块 P, 主对照 RND-J; 优先级自上而下首个满足者生效)
标签集 (f0,n0,f1,n1) = ((R0,free),(R0,noisy),(R1,free),(R1,noisy))。**STRONG** 当且仅当规则要求"非 D"的每个格都标 E (而非仅 I); 否则 TENTATIVE (V-NONE 本身要求四格全 E, 故只有 STRONG)。
| 判定 | 条件 | 授权的说法 | 不授权 |
|---|---|---|---|
| V-NONE | 四格全标 E (无 D 且无 I; 有 D 为零但含 I 的归 V-INS) | 共同固定配置下 JR 缺口未复现; JR 缺口不归因于噪声或表示, 可能是调参协议/图集特定 (交块 S 与 JR 配置对照) | 不说 "分组有效" (只说本设计未见缺口) |
| V-OPT | f0 = D | 无噪且精确可表示时仍有缺口: 属分组/优化效率差 (在此预算下), 与噪声和表示无关; 块 X 区分"预算受限"与"最优点更差" | 不说机制 |
| V-N | n0 = D 且 n1 = D 且 f1 ≠ D (STRONG 要求 f0 = f1 = E) | 缺口只在有噪格出现: 噪声交互 | 不说"联合修复更会拟合噪声" (这是推测, 除非 nf/Qfit 诊断同向) |
| V-R | f1 = D 且 n1 = D 且 n0 ≠ D (STRONG 要求 f0 = n0 = E) | 缺口随表示误差出现且无噪也在: 表示交互 | 不说"需要出生/分裂/合并" (推测) |
| V-NR | 仅 n1 = D, 且 I_interaction 上界 < 0 (STRONG 要求 f0 = n0 = f1 = E) | 需要噪声与表示误差同时存在 | 同上 |
| V-CO | n0 = D 且 f1 = D 且 n1 = D 且 f0 ≠ D (STRONG 要求 f0 = E) | 两个单因子各自起作用 | 不拆比例 |
| V-INS | 其余 | 证据不足, 不归因; 只许提出一个有界的判别性补充实验 | 不推进新机制 |
- 每个判定在终态报告中**同时**给出: 效应层证据 (本合同预注册的统计量)、机制诊断 (§5 辅助指标, 只作为关联)、推测 (明确标注)、未排除项 (§8)。
- 并列次对照 (IND1/OBS-I/SPA-J) 和块 S 各自按同一表判定并列报告。若主对照与某次对照判定不同, 明写"对照依赖", 不择优。

## 9. 并行诊断 E-B: 组级有限歧义 (设计阶段表 + 实例级协变量; 不进入判定)
- 定义 (白化, σ=SN): D_img = ‖x0 − x1‖/σ (锐利图差); d = ‖A(x0 − x1)‖/σ (模糊且白化的均值距离)。两个已知简单假设、等先验、已知协方差 σ²I 下的最小错误率 = Φ(−d/2) (MC 单测核查)。**歧义**当且仅当结构差 ≥ 15% 参考范数 (rel = D_img/‖x0‖/σ ≥ 0.15) 且 d ≤ 3 (Φ(−1.5) = 6.7% 错误率)。该公式只对两幅已知候选成立; 候选随数据搜索、背景需拟合、多重比较时须另行校准, 不能套用; 整幅噪声范数 σ√M 不是两个固定结构的可区分阈值 (Codex 勘误)。
- 配对: 成对细线 vs 单宽线 (质量、质心、横向方差匹配: st² + (s/2)² = sw²) 在 4 核 × 6 取向 × 3 宽 × 5 间距; 断续边 vs 连续边 (间隙 1–6 px); 纹理取向对; 参数重排负对照 (顺序交换、权重拆分: D_img 必为 0)。
- 谱: 组渲染 Jacobian 的正交基 (奇异值相对 1e-6 以下的渲染不变 "规范" 方向剔除) 的白化观测谱; 邻居固定 vs 邻居重拟合 (投影消元) 分别报告; 线性谱与有限幅度渲染分别报告; 单原语最弱观测度与组最弱观测度分别报告。
- 实例级 (探索性协变量): 对每个 CONFIRM 图的 R0 真值 (θ 已知), 每对中心距 ≤ 6 px 且两个权重均为正的原语, 用矩匹配的单 Gaussian 替换 (质量、均值、协方差匹配), 计算 pair-local 的 rel、d, 数出"歧义合并"个数, 逐核报告 (带符号权重的对无定义, 跳过并计数披露, DEV 中某些图被跳过多达一半的近邻对, 故该协变量只对正权重近邻对有意义); 对每图缺口的 Spearman 仅作描述 (n=16, 无推断)。
- 阅读限制: E-B 回答"有限歧义在这个噪声与这些核下是否存在", 不回答"检测器能否识别"。已确认 (设计阶段表, §15): σ=0.02 下匹配矩的真歧义基本只出现在强各向异性核 (AG) 且线垂直于模糊轴的取向; 各向同性高斯与圆盘几乎没有。故若 E-B 与 V-* 判定不一致, 不据此改判。

## 10. 强 INR 参考与近邻核对设计 (本节点不运行, 为后续经验桥接节点预写, 不弱化对照)
- 同目标: 同一逆问题 (已知 A、同一 y、同一 F_a 的数据项与同一 a)、同一真值、同一 W 网格下的 PSNR 曲线。INR 参考: 坐标 MLP (傅里叶特征, 3×64) 或多分辨率哈希网格, Adam, 学习率与特征带宽仅在 DEV 上调, 与 Gaussian 方法同等的调参预算; 工作量用同一 flop 代理计 (前向/反向/A 的稀疏乘); 另报告墙钟。必须同时给 INR 的"最佳停止"与"固定预算终点"两列, 与 Gaussian 方法同口径。
- 近邻核对 (后续任一方法声称前必做): PCAT/BUQO/TaskUQ/DDNM/AIR/López-Tapia/StarNet-BLISS/Raue/Explorable SR 逐条核对具体机制 (见 G0 日志); 不得以缩弱对照、改指标或更名处理负结果。
- 经验桥接: 已知核单图去模糊只是机制试验; 主张前至少需一个 P1817 经验桥接 (去噪/超分/CT) 并在新数据、不可调的独立留出集、相同预算与显式强基线上取得绝对质量。

## 15. 先验诚实记录 (设计阶段, 写在 CONFIRM 之前; 全是 DEV/CAL/SMOKE, 不是证据)
- hi 层生成器调整 (仅依据 CAL 851–870 与 DEV 的 K 拟合 PSNR, 未看任何方法结果): 初版 hi 的 K=36 表示 PSNR 为 35–40 dB (太易), 改为 碎片多边形 11–16 个 (半径 2.5–6 px)、光栅 5–8 项 (频率 4–10 周/图)、成对细线 14–18 对、边+光栅混合, 得 CAL 3 起点上界估计: 边族 ≈ 27–33 dB、光栅族 ≈ 25–39 dB (多数 26–30)、线族 ≈ 29–35 dB、边+光栅族 ≈ 27–34 dB; DEV 8 起点拟合: 801 39.2 (lo)、802 50.5 (lo)、803 34.9、804 31.6、805 29.1、806 38.8、807 34.5、808 31.3 dB。故 hi 层中位约 31 dB, 范围约 25–39 dB, 不保证每个 CONFIRM 图都落在 27–32 dB, 以 psnr_rep 逐图报告并作剂量响应。
- E-B 设计表 (outputs/CA/EB_design.txt): 线对 432 对中仅 16 对歧义 (AG 15, MO 1, G15 与 DK 0); 断续边 80 对 0 歧义; 纹理取向对 48 对 7 个 (AG 6, G15 1); 参数重排对照 D_img = d = 0; Φ(−d/2) 的 MC 与公式一致 (如 d=1.03: 0.303 vs 0.304 ± 0.002)。
- DEV 先导 (块 P, 801–808 = 2 个 lo + 6 个 hi, 8 图 × 4 核 × 4 格 × 5 臂 = 640 次运行, 全部 stop='cap'; outputs/CA/dev_REDUCE_P.txt; **非证据**, 仅用于定 n、预算与规则细节; 该先导中 BCa 标签在 n=8 下多为 I):
  - 方差/功效: OBS-J−RND-J 各格的跨图 SD 0.25–0.45 dB; 对比的 SD: N 0.21、R 0.19、交互 0.39。按 √(8/16) 缩放, n=16 的 MDE80 ≈ N 0.13、R 0.12、交互 0.24 dB, 单格缺口 ≈ 0.25 dB (与 δ_D=0.25 同量级, 故 δ_D 在 n=16 下刚好可被检出, 不再收紧)。
  - 墙钟: 640 次运行 63 min (2 核), 约 11.8 核·s/次。外推: 块 P 1280 次 ≈ 2.1 h, 块 S 768 次 ≈ 1.3 h, K 拟合 16 图 ≈ 8 min (2 核), 合计 ≈ 3.5 h。
  - 预算受限: 无噪格所有臂都在 cap 处停止且峰值 ≈ 终点 (仍在改善), 无噪格的缺口是"固定预算下的效率", 不是"最优点"(U2); R0/free 的 Q-AUC ≈ 24 dB 远低于可表示的上限。块 X 的动机成立。
  - 方向性线索 (非证据): OBS-J−RND-J 在无噪格 +0.13 (R0) / −0.02 (R1) dB, 在有噪格 −0.38 / −0.44 dB; N_effect −0.47 [−0.59, −0.36], 8/8 图为负; R_effect −0.11; 交互 +0.09 (SD 0.39)。OBS-J−IND1 四格皆负 (−0.29/−0.24/−0.46/−0.33)。分解: RND-J−IND1 在无噪格 −0.42/−0.43, 有噪格 +0.15/+0.11, 即 "联合 vs 独立" 的符号随噪声翻转, 而 OBS 分组相对随机分组的差只在有噪格出现。机制诊断 (只作关联): OBS-J−RND-J 的终点 PSNR 在有噪格 −0.58/−0.67 而峰值仅 −0.07/−0.13 (峰后下降更多); 噪声吸收比 nf 的差仅 +0.011/+0.015 (量级很小); 匹配数据拟合处的 PSNR (Qfit) 为负。故若 CONFIRM 出现类似模式, V-N 与 "对 IND1 的缺口不依赖噪声" 可能并列出现 → 并列报告, 不择优 (§7)。
  - 实例级合并负荷 (DEV R0 真值, outputs/CA/dev_EB_load.txt): 正权重近邻对中歧义合并数在 AG 核最多 (如 891: 8/84, 803: 7/75), G15/DK 次之 (0–3), MO 最少 (0–4); 部分图因负权重被跳过多达一半的近邻对 (805: 33/90)。仅探索性协变量。
