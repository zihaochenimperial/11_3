## 0. 这份合同要回答什么、不回答什么
固定 K 个 2D 高斯 (K 不增长), 以同一个持续的图像空间正则目标
  F_a(θ) = ½||W(A x(θ) − y)||² + (a/2)||x(θ) − x_ref||²,  x_ref = 0, W = σ_n⁻¹ I, a ≥ 0
求几何+振幅 θ ∈ R^p (p = 6K)。a 是任务正则 (目标的一部分, 对所有求解器相同); η (下文) 只是逐步信赖域阻尼, 不属于目标。
三个问题 **分别报告, 不做分解**:
- Q1 正则项的作用: 同一求解器, F_a(a*) 的解 vs 无正则 F_0 (含偏差原理早停) 的重建质量。
- Q2 联合计算的作用: 图像基联合求解 (GEO) vs 同目标的逐高斯块求解, 在相同预算下的目标值/质量/代价。
- Q3 真实算法瓶颈: 在最强的普通实现 (密集 LM、matrix-free LSMR/PCG 之一) 上, 每步时间由什么阶段主导, 是否可优化 (为日后局部两级求解器定位, 本合同不实现它)。
**不声称**: 原创性、求解器新颖性 (GEO 的一步 = 图像度量阻尼的正则化 Gauss-Newton/LM; matrix-free PCG-LM 已在 3DGS 发表: 3DGS-LM arXiv 2409.12892, 见 G0 行 C76)、跨数据泛化、对增长/选择的任何结论。唯一可能的“贡献候选”是实证性的: 在退化观测 + 固定 K 下, 正则目标/联合求解/代价结构的效应量; 在 G0 补完 (§10) 与独立确认前一律标 proposed。

## 1. 记号与精确的一步 (GEO)
x(θ) = Σ_k g_k ∈ R^m (m = N²); J = ∂x/∂θ ∈ R^{m×p}; A 退化算子 (S2 的 Op: A = B⊗B, 高斯模糊 sb ∈ {1,2}); r = y − A x。
单步子问题 (η > 0 是信赖域阻尼, 图像度量):
  min_δ ½||W(r − A J δ)||² + (a/2)||x + Jδ||² + (η/2)||Jδ||²
正规方程 P: (JᵀAᵀW²AJ + (a+η) JᵀJ) δ = JᵀAᵀW² r − a Jᵀ x。
因 M = AᵀW²A + (a+η)I ≻ 0 (η>0), P 的解集 = δ_min + null(J), 且图像步 Jδ 唯一。
GEO 实现: J = U Σ Vᵀ (约化 SVD; 丢弃 σ_i ≤ 1e-10 σ_1 的方向, 记录秩 ρ_t); z = Σ Vᵀ δ (Jδ = U z); B = W A U (m×ρ);
  (BᵀB + (a+η) I) z = Bᵀ W r − a Uᵀ x     (ρ×ρ 对称正定)
  δ = V Σ⁻¹ z   (参数空间最小范数原像, 参数缩放 S = I; 所有方法在同一 θ=(a,mx,my,l11,l21,l22) 坐标下)。
这在数学上等价于: 对 P 做 CG/LSMR **从 δ=0 起** 的极限 (Krylov 空间 ⊂ range(Jᵀ), 得最小欧氏范数解), 也等价于在参数空间对 P 用伪逆求解。因此 GEO、LSMR(tol→0)、PCG(→收敛) 的单步图像更新应一致 (单元测试, §6); 它们的差别只可能来自截断/容差/数值稳定与代价, 不是“更好的方向”。
η 的调度: η_t = κ_t · λ_max(BᵀB) (无量纲 κ), κ_0 = 1e-3; 步被接受且 ρ_gain ≥ 0.75 → κ←max(κ/3,1e-9); 被拒绝 → κ←4κ 并重试 (每外迭代至多 10 次回溯); ρ_gain = (F_a(θ) − F_a(θ'))/pred, pred = m(0) − m(z), m(z) = ½||W(r − A U z)||² + (a/2)||x + U z||² (不含 η)。
接受准则 (所有求解器统一): θ' = clamp(θ + δ) (S2 的盒约束: 位置[-4,N+4], log-Cholesky 对角∈[log0.6,log12], l21∈[-12,12]; 振幅无界 — 这是所有臂共有的可行集), **实际 F_a(θ') < F_a(θ) 且 ρ_gain ≥ 1e-4** 才接受; 额外非线性守卫: ||x(θ') − x(θ) − U z|| ≤ ||U z|| 否则视为拒绝并提高 κ。
停止: 外迭代 ≤ 60, 或连续 3 次接受步的相对下降 < 1e-9, 或 κ 达上限 1e3。每次求解还记录拒绝次数/秩/κ 轨迹。

## 3. 求解器臂 (全部同一初值、同一目标 F_a、同一可行集与接受准则; 各臂控制超参各自在 dev 上等量调优)
- HIST: S2 的 as_core.lm (目标为 0.5||r||²+1e-6Σa², Marquardt diag 缩放); 仅历史对照, 不是同一目标, 不参与 Q2/Q3 判定。
- LMD: “调好的正则 LM”: 参数空间密集解, 阻尼 λ·diag(H_a), H_a = JᵀAᵀW²AJ + a JᵀJ, 增减规则同 as_core.lm; 接受准则同 §1。
- GEO: §1。
- BLK: 逐高斯块: 一次扫描依固定顺序 k=1..K, 对每个高斯用当前残差解 6 参数块的同型子问题 (J_k = ∂x/∂θ_k, 图像度量阻尼, 块内 η_k), 块内按真实 F_a 下降接受, 然后更新残差再做下一个; 迭代数按扫描计。
- LSMR: matrix-free, 对 P 的增广最小二乘 [WAJ; √(a+η) J] δ ≈ [W r; −a x/√(a+η)] 用 scipy.sparse.linalg.lsmr (δ0=0, atol=btol=1e-10, maxiter=p); 仅用 J 与 Jᵀ 的乘法 (不形成 AJ)。
- PCG8: 3DGS-LM 式: 对 P 做 Jacobi 预条件的 PCG, 内迭代 ≤ 8, δ0=0 (若 8 步未收敛即使用截断解)。
- 像素域背景 (只作质量背景, 不同参数化): Tikhonov-SVD (λ 用 GCV; 另一行 λ 在 dev 上调), 两行。TV 与 INR 本合同不做 (列入 7 天阶段候选; INR 仅做代码准备, 不进 48h 判定)。
调优公平性: 每个求解器的控制超参至多 6 个组合 (GEO: κ_0∈{1e-4,1e-3,1e-2} × 回溯因子∈{3,10}; LMD: λ_0∈{1e-4,1e-3,1e-2} × 因子∈{3,10}; BLK: κ_0 同; LSMR/PCG8: κ_0 同), 用 dev 上“60 外迭代内几何均值 F 缺口 s (见 §4)”最小者选出并冻结; held-out 不再调。

## 4. 度量 (全部事前固定)
- 目标缺口: F_ref(单元) = 该单元所有求解器所有运行 + LMD 500 迭代 3 次重启 (同初值但扰动: 各 θ 位置 ±0.5 px 高斯扰动, 种子固定) 的最小 F_a; s(F) = (F − F_ref)/(F_init − F_ref)。F_ref 只在评估端计算。
- 达到代价: 首次 s ≤ 1e-2 与 s ≤ 1e-3 的外迭代数、A 乘法次数、J 构造次数、单线程墙钟 (中位数, 3 次重复)。
- 质量 (评估端读干净图): M = mean((x(θ̂) − x_true)²); H_X = 1 − exp(mean_i log(M_X/M_ref)) (正=X 更低 MSE; 以图像为单位)。
- 有效性: 接受步的 F_a 单调下降率 (必须 100%)、拒绝步/回溯数、秩 ρ_t、盒约束触发率。
- 对 Q1: M(F_a*, GEO 解) vs M(F_0 + 偏差原理早停, LMD: 首个满足 ||y − A x_j||² ≤ τ N² σ_n², τ=1) vs M(F_0 收敛) vs HIST 终点。

## 7. 判定规则 (GEO-3; 事前固定; 数字为实际显著性门槛, 供 Opus 审)
- 有效性 V-pass: V1-V6 全过; 且 dev 上 GEO 与 LMD 各有 ≥95% 单元在预算内 s ≤ 0.1。否则 STOP-GEO-V (记 FAIL, 不解读质量)。
- Q1 标签 (held-out, F_a* GEO 解 vs F_0+DP, 全 384 单元): REG-HELPS 若 H ≥ 0.05 且 t 区间不含 0 且 ≥3/4 条件 H ≥ 0; REG-HURTS 若 H ≤ −0.05 且区间不含 0; 否则 REG-NEUTRAL。同时报告对 F_0 收敛与 HIST 的 H。
- Q2 标签: JOINT-MATTERS 若同时 (a) 两个 K 层上 GEO 达 s≤1e-2 的墙钟中位数 ≤ 0.5×BLK 的, 或 BLK 在 ≥25% 单元于预算内未达 s≤1e-2 而 GEO ≥90% 达到; (b) GEO 对 BLK 的 H ≥ 0 (质量不更差, 区间下界 ≥ −0.02)。否则 JOINT-NOT-MATTERS。另报 GEO 对 LMD/LSMR/PCG8 的代价比 (GEO 不要求赢, 因 §1 已表明方向相同)。
- Q3 标签 (阶段 L): 取每尺寸上“达到相同 s≤1e-2 的最快普通臂”(LMD/LSMR/PCG8 中), BOTTLENECK-OPTIMISABLE 若在最大两个可跑尺寸上 (A 作用 + 线性求解) 占迭代时间 ≥50% 且该合计阶段时间对 K 的对数斜率 ≥1.5, 且 Gram 耦合稀疏度 (非零块比例) ≤0.3 于最大尺寸; ASSEMBLY-BOUND 若 Gaussian 渲染+J 构造占 ≥50%; 否则 FLAT。
- 推进: ADVANCE-7D (7 天局部两级求解器) 仅当 V-pass ∧ JOINT-MATTERS ∧ BOTTLENECK-OPTIMISABLE; REDIRECT-REG (只保留正则目标/α 协议, 加 TV/INR 对照, 不做求解器主张) 若 REG-HELPS 但 Q2/Q3 任一不过; 其余 STOP-GEO (记入 FAILURES, 保留全部数字)。ADVANCE 不需要再问真人 (真人授权已含), 但需新的 7 天合同 + 真实 Opus 门 + 冻结。

## 9. 已知局限 (事先写下)
- 固定 K、小图 (N=32), 非高斯程序化图像; 结论不外推。
- GEO 与 LSMR/CG-from-0 数学等价 (§1), 因此 Q2 实质是“联合 (含耦合) 求解 vs 块坐标”, Q3 是“实现层面的代价结构”; 二者都不是新的方向性主张。
- α 表由 dev 调定 (用了干净图 MSE), 依赖已知 σ_n/sb; 不是 y-only 规则。
- F_ref 是启发式参考 (多算法+重启的最小), 不是全局最优。
- 计时依赖本机 (i7-12700H, 单线程, 作业独占); 绝对数无外推意义。
