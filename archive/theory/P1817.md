# P1817 theoretical validation, v0

Let a noisy pixel be `y_j = x_j + ε_j`, with `E[ε_j | x,A]=0` and noise at held-out pixel `j` independent of the fit/proposal data A. For two **fixed** candidate predictors `f0`, `f1` trained/proposed without `y_j`, put `Δ_j=f1(j)-f0(j)`. The noisy held-out improvement is

`d_j = (y_j-f0(j))² - (y_j-f1(j))² = 2(y_j-f0(j))Δ_j - Δ_j²`.

Conditional expectation over `ε_j` gives `E[d_j|x,A] = (x_j-f0(j))² - (x_j-f1(j))²`. Thus noisy held-out improvement is an unbiased estimator of clean squared-error improvement for a fixed candidate; unknown common noise variance cancels. This does **not** establish that the selected candidate improves: repeated selection using B makes its B score optimistic. Use A for fitting/proposal, B for choosing, C for independent audit. If output on every pixel must be J-invariant, rotate three roles so the target fold is neither fit nor selection data; use untouched test images for final method evaluation.

Conditions to test: independent/zero-mean noise, mask-safe initialization and proposal, enough held-out pixels per local batch, fixed candidate count or predeclared sequential decision rule. Correlated sensor noise and selection using the target fold invalidate the simple identity.

CPU-only sanity run: `node theory/holdout_selection_sanity.js` (10,000 synthetic trials, signal zero, 16 pixels per fold). Fixed candidate noisy gain `-0.01050` versus clean gain `-0.01000`. Picking from 21 candidates using B yields apparent B gain `+0.06342`, but independent C gain `-0.06099` and clean gain `-0.05937`. This demonstrates selection optimism in a toy setting, not a result about Gaussian denoising.

Closest verified work: [Image-GS](https://arxiv.org/html/2407.01866) already does residual-guided Gaussian allocation and noisy-image restoration; [Luxar](https://github.com/royerlab/luxar/blob/318eee294ac9909cf27ca12670022455bb7b5de8/docs/tutorials/gaussian_splatting.rst#L315) already uses blind-spot Gaussian-count calibration, including region-scoped calibration and density transfer into per-box budgets; [Noise2Self](https://proceedings.mlr.press/v97/batson19a.html) gives the blind-spot principle; [Kim/Fridovich-Keil](https://arxiv.org/html/2506.11139v3) compares GSplat, INR and TV-grid on inverse problems. Image-GS and GaussianImage++ also already have local sequential residual-driven births. The defensible candidate is therefore a **specific leakage-safe sequential rule that accepts or rejects individual local Gaussian edits using held-out pixels**, and it must beat calibrated regional budgets as well as residual birth. This is a bounded novelty hypothesis, not established priority or efficacy.
