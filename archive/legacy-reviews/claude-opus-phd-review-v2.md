## 1. 更正首轮站不住的可识别性说法

1. **"颜色几乎总能识别"是错的。** 两个 Gaussian 位置和尺度相同时，π_i 与 π_j 成比例，只有颜色的组合能识别。下采样时，亚像素原语会和邻居混叠。top-K 截断也会让 π_i 局部为零。
2. **"几何 Fisher ∝‖c_i−c_j‖²"只在两原语、无截断的特例成立。** 一般情形下这一项是 (c_i−x(p))。单个 Gaussian 的对角块会**误报可识别**，因为邻居可以补偿。应改用扣除邻居后的 Schur 补块 F_ii−F_{i,−i}F_{−i,−i}⁻¹F_{−i,i}，或者看它在 Ax 上的投影效应。
3. **原始特征值依赖单位和参数化。** 例如尺度和 log 尺度、像素单位，都会改变数值大小，所以不能跨块比较。光滑重参数化下只有秩不变；可比的量要定义在测量空间里。
4. **置换对称和分裂对称**意味着只能在商空间里谈局部可识别。**birth 时子 Gaussian 复制父 Gaussian，Fisher 恰好奇异**，所以 Fisher 不能直接拿来当 birth 判据。
5. **曲率大不等于扩展有用。** Fisher 只刻画方差代价，收益来自近似偏差的下降，两者都要估计——这本身就是风险框架。
6. **CRB 是无偏且正则条件下的下界，不保证取等号。** 非凸优化加 top-K 的估计量不满足这些条件。所以首轮的"1.5–2 倍"不能当检验标准，只能检查界有没有被违背、排序是否一致。
7. **s²/d 过渡宽度**只是没有验证过的启发式。
8. **模糊会让留出像素和拟合像素的信号相关。** 留出法真正需要的是**测量空间里的噪声独立**：白噪声加在 A 之后时成立，去马赛克或压缩噪声则不成立。
9. **像素一般不可交换**，所以 Mondrian conformal 不会自动有效。

首轮给出的所有阈值都只是我的建议，不是已经约定的合同。

## 2. 判定

**目前不构成三项独立、原创、可行的博士贡献。** 现有的是一个可能新颖、但尚未证实的首贡献，外加两个条件分支。三者共享同一个机制，硬拆成三项是凑数。

## 3. 最佳首贡献：带搜索修正的风险核算

**命题**：在噪声模型和算子已知时，贪心 birth/冻结的真实风险会被"最终模型自由度"系统性低估。用随机化 birth 加全流水线 MC-SURE/GSURE，可以在单图内纠正这个低估，并据此决定 birth 和停止。

**和近邻的区别：**
- **PUP**：在干净的多视图数据上用二阶敏感度剪枝，不估噪声风险，也不处理选择偏差。
- **FisherRF**：用 Fisher 选视角、估不确定性，决策对象不同。
- **Jia 的 NIW Bayesian GS**：做贝叶斯几何后验、DP 复杂度信号和区间校准，是"复杂度决策"上**最近的竞争者**。我们做的是频率学风险加搜索修正，场景是 2D 逆问题。**必须把它的复杂度信号或 BIC/证据近似列为基线**，否则差异只剩 3D→2D 的迁移。
- **Feng**：算子级稳定性理论，只覆盖加性模型，不含 A，也没有算法。
- **经典 SURE、DIP-SURE、Jo 2021**：对固定结构做早停时估 df；Tibshirani 则只给 best subset 定义了 search df。我们面对的是离散、贪心、带非线性几何的原语增长。
- **坦白说**：这本质上是把已知理论用到一类新的估计器上。它能否成为贡献，取决于两点：实测到的搜索偏差足够大，而且 DIP-SURE 式的整体散度估计修不好它。

**仍未验证：**
- DIP-SURE 原文、Metzler 2018、Tibshirani 正文。
- GaussianImage++、AIR、SAD 的选择准则。
- 是否已有 GS 或 INR 文献做过 search-aware 的自适应增密。
- top-K 不连续时，随机化后的 Stein 引理是否还成立。

## 5. 首批证伪实验

这些实验都需要先写冻结合同。P1817 目前的 NO LAUNCH 状态不变。

**8GB（大部分可以只用 CPU）：**
- **F0：搜索偏差是否真的存在。**
  - 设置：64²–128² 的合成图，干净图已知，σ 已知，从 256 个候选里贪心选 64 个。
  - 用多次噪声抽样做 Efron 协方差 oracle df，对比参数计数、线性化迹和 DIP-SURE 式整体散度。
  - 如果朴素估计已经落在 oracle 的 MC 误差范围内，首贡献的核心就不存在，立即停止。
- **F1：估计器和决策是否一致。** 看随机化 MC-SURE 对 oracle 风险的排序和决策是否一致。基线包括 holdout 选全局 K、固定 K、移植过来的 DIP-SURE 早停，以及 BIC/证据近似。
- **F2：可识别性反例。** 在复制分裂、邻居补偿、换单位三种情形下，比较对角块和 Schur 补块的预测差异。

**24–36GB：只在 F0/F1 通过后才需要。** 用途是：
- 在未触碰的 Kodak/CBSD68 级测试集上跑多 σ、多算子、多个噪声和优化 seed。
- 处理 512² 以上的图像、需要多次前向的 MC 探针，以及去模糊/超分辨率下更大的 K。

它不是证伪的前提。

## 6. "算贡献"而不是"代码能跑"的判据

1. 现有做法的缺陷是**实测出来的**：在合成 oracle 下，跨图像、跨 σ 都能复现。
2. 在明示的假设下，方法可以对照 oracle 检验；并报告假设失效时的表现，例如 σ 设错或噪声相关。
3. 有**决策层面**的收益：在同等计算量下对比最强的公平基线，在冻结后未触碰的测试集上给出配对置信区间。做不到的话，就给出同样严谨的负结果。
4. 和全文读过的最近邻做方法级对照，并通过独立审查。

具体阈值由冻结合同规定，这里不设定。
